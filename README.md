# 아이디어 제작소 (idea-lab)

메인 페이지(`index.html`)에 아이디어 카드가 하나씩 쌓이고, 카드를 누르면 각 아이디어 페이지(`ideas/번호-이름/`)로 이동합니다.

## 구조

```
idea-lab/
├─ index.html          메인(카드 목록). 거의 안 고칩니다
├─ ideas.js            아이디어 목록. 새 아이디어는 여기에 한 줄 추가
├─ .nojekyll           GitHub Pages가 파일을 그대로 서비스하도록 함
└─ ideas/
   ├─ _template/       새 아이디어 시작용 틀 (복사해서 사용)
   └─ 001-menu-roulette/   샘플
```

## 새 아이디어 추가 순서

1. `ideas/_template` 폴더를 복사해 `ideas/002-이름/`으로 만든다.
2. 그 안의 `index.html`을 아이디어에 맞게 채운다.
3. `ideas.js` 맨 위에 항목(번호·제목·요약·태그·날짜·폴더명)을 추가한다.
4. 커밋하고 push 하면 사이트에 반영된다.

## 지킬 것 (공개 저장소)

- 의뢰인 개인정보·사업 정보·연락처는 **동의 없이** 넣지 않는다.
- 비밀번호, API 키, 회사 자료는 절대 넣지 않는다.
- 로그인·결제·개인정보 저장이 필요한 기능은 이곳에서 만들지 않는다.
- 파일 경로는 상대 경로로 쓴다. (나중에 호스팅을 옮기기 쉽게)
